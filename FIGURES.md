# Figures

All figures are generated by `make_figures.py` from the files in `analysis/`
and written as PDFs to `figures/`.

```bash
python3 make_figures.py
```

## Predicted vs. true performance

`figures/predicted_vs_true_atari3.pdf`, `figures/predicted_vs_true_atari1.pdf`,
`figures/predicted_vs_true_combined.pdf`

Scatter of each method's true 26-game median HNS against the median HNS
predicted from the selected Atari-3 test games (or the Atari-1 validation
game), on a log-log scale. Points on the diagonal are predicted exactly;
distance from the diagonal shows the prediction error. The combined figure
places both panels side by side, titled "Test Environments" and "Validation
Environment".

## Game correlations

`figures/correlation.pdf`

Heatmap of the pairwise Pearson correlation between games' log-transformed
HNS across all methods. Used to sanity-check that the selected games aren't
redundant with each other.

## Mean HNS over time

`figures/hns_over_time.pdf`

Scatter of each method's release date against its mean HNS across the 26
games, illustrating the improvement in Atari-100k data efficiency over time
(Rainbow, DER, SPR, SR-SPR, BBF).
